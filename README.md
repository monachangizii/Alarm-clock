# ⏰ Alarm Clock

A fully functional **Alarm Clock** application built with **Python (PyQt5)** and **MySQL**.  
This project allows users to set, manage, and delete alarms with labels, providing a smooth and customizable alarm experience.

---

## ✨ Features
- Add new alarms with custom labels and time.
- Display all active alarms in the main window.
- Enable/disable alarms with a toggle switch.
- Delete alarms from both the interface and database.
- Popup notification when an alarm time is reached.
- Persistent storage of alarms using **MySQL database**.

---

## 📦 Tech Stack
- **Python 3.12**
- **PyQt5** (UI and widgets)
- **QTimer** (time tracking and scheduling)
- **MySQL** (database for alarm storage)
